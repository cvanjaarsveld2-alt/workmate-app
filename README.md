# WorkMate PWA

Installable field service and sales assistant prototype.

## Run locally
```bash
npm install
npm run dev
```

## Deploy to Vercel
1. Create a free Vercel account.
2. Click Add New Project.
3. Upload/import this project.
4. Framework preset: Vite.
5. Build command: `npm run build`
6. Output directory: `dist`
7. Deploy.

## Install on phone
### iPhone
Open the deployed HTTPS link in Safari → Share → Add to Home Screen.

### Android
Open the deployed HTTPS link in Chrome → three dots → Install app / Add to Home Screen.

## Notes
Calendar connection and push notifications are UI placeholders in this prototype.
Real Google/Outlook sync and notifications need OAuth + backend setup.
